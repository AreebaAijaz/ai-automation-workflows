📖 ## Project Overview

This project is a modern e-commerce website built with Next.js and Tailwind CSS.
It showcases a clean and responsive online shopping interface where users can explore various categories and products.

Recently, I enhanced this project by integrating an AI Chatbot that assists visitors directly on the website — making the shopping experience more interactive and helpful.
🔗 You can check this live at:
Website: https://hackathon-2-areebaaijaz.vercel.app/


💬 ## Chatbot Integration

The chatbot is powered by n8n, a workflow automation platform.
Here’s how the integration works:

A workflow is created in n8n Cloud using the “When Chat Message Received” trigger node.

Each message from the user is sent to an AI Agent Node inside n8n, which processes and generates an intelligent response.

The chatbot is connected to the website using the Chat Trigger URL generated by n8n (deployed via Render.com).

The site communicates with this endpoint through API requests — providing real-time chat interaction with no backend hosting required.
